- 平台事实：本机 MacBook Air M4 (Mac16,12)，macOS 27.0.1 (26A434)，Darwin 27.0.0 arm64 原生；Rosetta 未安装（无法做 live 负面测试，gate 逻辑靠单测）。
- 关键平台差异（已 PROVEN）：macOS CPython 无 os.*xattr → libc fsetxattr/fgetxattr/flistxattr ctypes 封装；fcopyfile(COPYFILE_METADATA)=(1<<0)|(1<<1)|(1<<2) 保留 mode+xattr+ACL 且不动内容；getpeereid 返回 euid/egid 无 PID；Darwin sun_path 104 字节（含 NUL），socket 路径必须在 bind 前 ≤103 校验；chmod +a 需要用户名+entry 分开两个参数。
- 设计决定：mutations.py 保留为共享 POSIX 核心，metadata 保存策略参数化（Linux 默认不变，Darwin 用 fcopyfile）；search_scan.py（rg 64KiB NUL 截断语义）与 read_page.py 提取共享；codex_linux.py→codex_posix.py 重命名（POSIX-generic）；backends.get_backend 显式 dispatch，非 linux/darwin/win → NATIVE_PLATFORM_UNSUPPORTED。
- macOS uv CPython 的 libpython 通过 @executable_path/../lib 链接 → 拷贝解释器无法运行（测试用 shebang shim 替代）。
- launchd 实测：bootstrap/print/kickstart -k/bootout 全通过；state 词汇 running|active；bootout 后进程消失；不声称 descendant containment（保留 recovery guard）。
- 测试门控约定：Linux-kernel contract 测试在非 Linux 跳过（conftest collect_ignore / platform_contract）；Darwin 测试文件以 sys.platform=='darwin' 门控；live launchd 测试需 SERVERFS_LIVE_LAUNCHD=1。
- 遗留（需用户 secrets/环境）：ChatGPT tunnel E2E（需真实 tunnel_id+API key）、真实代理 egress 证据、Qoder live（本机无 qodercli）。CI：macos-native.yml 用 macos-27 runner + 实测断言；PR #41 上 Linux/Windows/CI 等待结果。
