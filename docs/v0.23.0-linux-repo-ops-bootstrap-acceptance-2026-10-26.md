## Scope

The accepted development capability is a per-workdir, default-off, deterministic non-Agent repository surface implemented through the existing authenticated host Bridge transport:

- `inspect_repo`
- `run_repo_action`
- `commit_repo_changes`
- `push_repo`

Repo Ops is independently authorized from Agent delegation. It does not select a model/runtime, create an Agent task/session, invoke a provider adapter, or expose a generic shell/argv/environment/remote/ref/force surface.

The first accepted implementation scope is Linux only. Native Windows/macOS Repo Ops is not claimed by this record.
