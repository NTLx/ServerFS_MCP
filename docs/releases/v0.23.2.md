# ServerFS v0.23.2 — Native Windows Deterministic Repo Ops

ServerFS v0.23.2 is a maintenance release that extends independently gated **Deterministic Repo Ops** to validated native **Windows 11 x64** deployments, alongside the Linux Host Bridge support introduced in v0.23.0 and validated native Apple Silicon macOS support added in v0.23.1.

Repo Ops keeps the same narrow public contract: four MCP tools (`inspect_repo`, `run_repo_action`, `commit_repo_changes`, `push_repo`), operator-owned fixed/integrity-pinned actions, explicit repository mutations, and no generic shell or caller-controlled executable/argv/environment/remote/ref/force surface. Repo Ops does not select a model, create an Agent task/provider session, or fall back to Agent delegation.

## Windows-native containment

v0.23.2 closes the Windows-specific execution gaps required to make that existing contract native rather than merely portable:

- Workdir/repository validation rejects NTFS reparse points and junctions before Repo Ops execution.
- Repo Ops child processes are created suspended, assigned to the Bridge-owned Job Object, and only then resumed.
- Timeout, cancellation and output-overflow cleanup converges the descendant process tree before the shared writer lease is released.
- If descendant cleanup cannot be proven, the operation fails closed and keeps the writer lease until an external Bridge generation restart, rather than exposing a potentially concurrent writer.
- Hardened Git-for-Windows execution stays non-interactive with a narrow environment, disables hooks/signing/askpass/SSH overrides, and uses the native `NUL` sink where needed.

The Windows lifecycle remains current-user and non-elevated through Task Scheduler 2.0; this release does not introduce SCM/LocalSystem services, administrator requirements, a generic command executor, or a second repository policy model.

## Platform boundary

The current Repo Ops support matrix is:

- **Linux Host Bridge** — released in v0.23.0.
- **Native Apple Silicon macOS** — validated in v0.23.1 within the existing Apple Silicon arm64 / macOS 27 / local APFS contract.
- **Native Windows 11 x64** — validated in v0.23.2 within the existing current-user / local NTFS native contract.

Linux Compose configuration remains Linux-specific; native Windows/macOS policy continues to use `serverfs.toml`. Repo Ops remains independently gated from Agent delegation on all supported platforms.
