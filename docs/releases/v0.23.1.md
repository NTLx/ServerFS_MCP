# ServerFS v0.23.1 — Native macOS Deterministic Repo Ops

ServerFS v0.23.1 is a maintenance release enabling independently gated Deterministic Repo Ops on validated native Apple Silicon macOS, alongside the existing Linux Host Bridge support. Native Windows Repo Ops remains unsupported.

Repo Ops retains the v0.23.0 security model: four narrow MCP tools, operator-fixed and integrity-pinned named actions, explicit repository mutations, and no generic shell or caller-controlled executable/argv/environment/remote/ref/force interface. Repo Ops never selects a model, creates an Agent task, or falls back to Agent delegation.

## Native macOS acceptance

On Apple Silicon arm64 running macOS 27.0.1, the full root gate passed (Ruff/format; 1610 passed, 401 skipped) and the full Agent Bridge gate passed (Ruff/format; 457 passed, 94 skipped). The ServiceManagement companion built with a valid app signature/designated requirement, the root wheel built with required companion sources/assets, and the native configuration/Bridge policy doctor reported 0 FAIL and 0 WARN.

A controlled managed-service hand-over/restart loaded Bridge version 0.23.0 from the checkout and observed the expected `BRIDGE_SHUTDOWN` boundary. Public MCP stdio E2E against the real managed Bridge exposed 27 tools, including all four Repo Ops tools and Agent tools. On a clean test workdir with one fixed read-only, integrity-pinned status action, action inspection returned only the configured action and `mutates=false`, repository inspection showed a clean `main` worktree, and execution returned code 0 with the expected Git status shape. No commit/push tool was called and Repo Ops submitted no Agent task.

The machine-local configuration was restored byte-for-byte after acceptance, Bridge policy was resynced, the doctor again reported 0 FAIL and 0 WARN, and a controlled restart completed. Both configured workdirs currently have Repo Ops disabled; Agent runtimes remain configured. Detailed redacted evidence is in [`macOS native Repo Ops acceptance`](../v0.23.1-macos-repo-ops-acceptance-2026-10-27.md).

## Platform boundary

Native macOS support remains limited to the existing Apple Silicon arm64 / macOS 27 contract. This release does not claim Intel, Rosetta, other macOS releases, or filesystem/architecture coverage beyond the existing native macOS support contract. Linux Compose examples remain Linux-specific. Native Windows Repo Ops remains unsupported.
