### Maintainer decision: local Agent memory (2026-11-26)

The maintainer identified the local `.remember` directory as Agent-owned
memory, outside ServerFS development. Do not commit it or block release solely
on its creation. A standalone Claude SDK connect reproduced it with normal
setting sources and not with empty sources; no query was made. Preserve native
settings and do not read or remove operator memory. The fixture policy permits
only an ordinary `.remember` directory in the submitted Agent-enabled alias.
Marker content, unsubmitted/sibling file-only and Repo-only aliases, unknown
extra entries and reparse-point substitutes remain protected. Git ignores
`.remember/` at all depths; no such paths were tracked at the parent commit.
Historical strict reports remain unchanged. Proxy routing, terminal behavior,
cancellation and cleanup remain separate evidence; a timeout is not a natural
provider failure.
