## Limits

Criterion 7 is accepted for the focused deterministic seams above. This evidence does not claim a platform-native service-manager query failure injection or a global syscall monitor. Collector-level no-repair/no-restart behavior is only directly exercised where an existing collector/test seam exists; the shared observation contract tests establish that unverified evidence cannot be represented as healthy. Those narrower gaps remain explicitly **Not verified** and do not imply a product implementation change.
