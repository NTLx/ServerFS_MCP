## Live diagnostics

The live current-user AF_UNIX endpoint is **REACHABLE** from the v0.22 CLI. Running
`serverfs diagnostics snapshot --format json` reached the running Bridge, which returned
`METHOD_NOT_FOUND: unknown bridge method: diagnostics.snapshot`. This is evidence that
the Mac Bridge process is an older implementation without the v0.22 diagnostics RPC;
it is not a diagnostics PASS.

Updating and restarting the managed Bridge must happen out-of-band from the Bridge.
Perform that safe upgrade/restart only after all active tasks are terminal and all
writer leases are released. Then repeat the live diagnostics acceptance against the
updated Bridge and record its result.
