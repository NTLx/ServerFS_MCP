# ServerFS v0.22.1 Release Checklist — 2026-10-23

Status: **v0.22.1 is published as a stable release.** This checklist preserves the release-preparation record and adds the verified post-release evidence below.

## Release summary

v0.22.1 is a maintenance release covering:

- Linux Agent Bridge installation now runs Python helpers from the staged release virtual environment after it has been created, avoiding dependence on the host's ambient `python3` version.
- macOS service restart waits for service registration, managed-process readiness, and Agent Bridge RPC health where the Bridge is enabled. Failure propagates instead of returning a successful lifecycle result prematurely.
- Bridge-only and Tunnel+Bridge self-restarts use a bounded one-shot launchd hand-over. Final success evidence is written only after the temporary launchd job and plist are verified absent.
- A Darwin test-isolation regression was fixed by mocking hand-over scheduling at the parent lifecycle boundary, preventing a root test run from stopping the developer's live Bridge.
- Maintainer guidance now forbids persistent/keepalive `launchctl submit` jobs for one-shot maintenance and requires cleanup verification.

No MCP schema, Agent Bridge RPC/provider behavior, configuration, or Windows lifecycle change is part of this maintenance scope.
