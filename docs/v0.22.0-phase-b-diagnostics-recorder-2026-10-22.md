# ServerFS v0.22.0 Phase B — Typed Diagnostics Recorder

Status: **Phase B complete; lifecycle instrumentation and external surfaces not started.**

Date: 2026-10-22. This phase implements the Bridge-local typed diagnostic contract and bounded in-memory recorder specified by `dev_plan_v0.22.md` §§4–8 and Phase B. It does not instrument `BridgeService` lifecycle seams.

## 1. Scope delivered

- `agent_bridge/src/serverfs_agent_bridge/diagnostics.py` defines catalog v1 operation/seal types, closed enums/domains, Bridge-generated `DiagnosticTraceContext`, and Bridge-local `DiagnosticStaging` so a monotonic submit start/context can be attached only after task creation.
- The synchronous `DiagnosticRecorder` enforces the frozen 2,048 global records, 1 MiB global logical payload, 64 records / 32 KiB per task, 1,024-byte operation and 512-byte terminal-seal reservation limits. Active slots reserve their seal record and bytes globally. Slot and not-retained indexes are bounded.
- Terminal operations are retained and evicted atomically, oldest `terminal_completed_at` first. A bounded min-heap tracks only retained terminal slots. If active slots block capacity, admission fails atomically or the current active trace becomes a continuous truncated prefix; the seal remains available.
- The recorder rejects sequence gaps/duplicates, seals exactly once, maps terminal outcomes to bounded reason codes, supports restarted completeness, and projects deterministic JSON without trace/span identity. A missing not-retained reason remains absent; restart is reported only when later lifecycle integration has evidence.
- Snapshot-only saturating counters cover record/admission failures, dropped ordinary recording, oversized operations and whole-task evictions. Recording/sealing/admission isolate ordinary exceptions and do not change task authority.
- `agent_bridge/tests/test_diagnostics.py` covers context staging, hard bounds/reservations, active-task non-eviction, terminal-time eviction order, contiguous prefix, exact seal/idempotency, restart states, rollups including negative unaccounted time, oversized operations, failure isolation, redaction and durable/public model exclusion.
- `agent_bridge/benchmarks/v022_diagnostics_recorder.py` consumes the Phase A catalog fixture and measures setup-excluded record/seal, one actual whole-terminal-task eviction + record, a fixed 2,048-record snapshot, and the 64-record task projection.

No SQLite/task/event/result/manifest persistence, Core carrier, MCP schema/tool, RPC method, root CLI, lifecycle instrumentation, OTel/exporter/dependency/config/version/site change was made. The Phase A plan, fixture and evidence remain present and unchanged.

## 3. Recorder microbenchmark

Executed three independent in-process runs, five samples per case:

```bash
uv run python benchmarks/v022_diagnostics_recorder.py --iterations 5 --runs 3
```

Cross-run median of each run's p95, milliseconds:

| Case | Run 1 | Run 2 | Run 3 | Median p95 | Plan budget | Result |
|---|---:|---:|---:|---:|---:|---|
| Ordinary non-evicting record | 0.030432 | 0.025175 | 0.019337 | **0.025175** | 0.20 | PASS |
| Terminal seal write | 0.056405 | 0.027680 | 0.020063 | **0.027680** | 0.25 | PASS |
| Whole completed-task eviction + record | 0.054735 | 0.045040 | 0.049052 | **0.049052** | 1.00 | PASS |
| Saturated snapshot | 0.493079 | 0.457462 | 0.472646 | **0.472646** | 10.00 | PASS |
| Maximum retained task projection | 0.092376 | 0.094354 | 0.065992 | **0.092376** | 5.00 | PASS |

Each eviction sample starts with 2,047 terminal seals and one pre-admitted active slot; an assertion verifies exactly one whole-task eviction per timed `record()`. Snapshot setup uses a fixed loop and asserts 2,048 retained records, with logical bytes within the 1 MiB hard ceiling. The maximum projection has 63 ordinary records plus one seal. Setup work is outside each timed action. Five samples per run make this an initial harness check, not a high-confidence performance acceptance run; Phase E must rerun with larger sample counts and process/resource measurements.
