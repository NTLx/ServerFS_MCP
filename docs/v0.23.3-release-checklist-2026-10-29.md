# ServerFS v0.23.3 Release Checklist — 2026-10-29

## Release objective

v0.23.3 closes the publication-gate defect exposed by v0.23.2 while retaining the validated native Windows 11 x64 Deterministic Repo Ops product behavior.

The release is valid only when the exact release SHA passes the complete reusable gate matrix **before** the stable tag is created.

## Release orchestration contract

- [ ] `.github/workflows/wheel-release.yml` is dispatch-first (`workflow_dispatch`) and does not publish from a raw tag push.
- [ ] Linux/Container, Windows Native, Windows Agent, macOS Native, and Pages workflows expose `workflow_call` release gates.
- [ ] Stable tag creation depends on every exact-SHA gate.
- [ ] Tag creation re-fetches `origin/main` after the gates and fails closed if main advanced.

- [ ] Stable GHCR publication is downstream of validated tag creation.
- [ ] Wheels / Agent Plugin / GitHub Release are downstream of validated tag creation.
- [ ] Ordinary `main` Container publication remains `:edge` only.
