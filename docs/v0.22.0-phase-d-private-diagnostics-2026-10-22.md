# ServerFS v0.22.0 Phase D — Private Diagnostics RPC and CLI

Status: **Phase D local RPC/CLI gate complete; Phase E and later phases are not started.**

Date: 2026-10-22. Phase D adds only local operator diagnostic queries over the existing
Agent Bridge transport. No MCP schema, listener, persistence, dependency, configuration,
version, site or platform lifecycle change was made.

## 1. Surface delivered

- Private Bridge RPC methods are `diagnostics.snapshot` with exact empty params and
  `diagnostics.task` with exactly one `task_id` string bounded to 256 UTF-8 bytes.
- The methods call Bridge service projections. Task lookup checks the Bridge TaskStore;
  the CLI has no SQLite access. Unknown, not-retained and retained task results remain
  distinct. A not-retained reason is returned only when the recorder has established one.
- The root CLI exposes `serverfs diagnostics snapshot` and
  `serverfs diagnostics task <task-id>`, with `--format human|json` (human default).
  JSON emits the Bridge object unchanged, including `catalog_version`. Human output is a
  stable sorted rendering of that same object. Bridge reachability failure produces the
  bounded `bridge_unavailable` envelope and exit status 1.
- The CLI uses `AgentBridgeClient` plus the existing endpoint derivation, retaining AF_UNIX
  peer checks and the Windows SID-verified Named Pipe transport. No new endpoint exists.
- The methods are not registered as MCP tools or resources. Snapshot is the recorder's
  aggregate projection; task output is the recorder allowlist projection and does not
  expose durable task fields, correlation, workdir/path, provider session/turn, model,
  prompt/result, provider payload, or diagnostic trace/span IDs.

## 2. Focused coverage

Root tests cover both private client method names/params, CLI JSON and human output,
stdout/stderr/exit behavior, Bridge unavailability, negative unaccounted time, and
restarted/truncated completeness rendering. The Bridge protocol tests cover snapshot
identity exclusion, available/unknown/not-retained dispositions, task projection
redaction, exact parameter shapes, the task ID byte bound and response size bound. The
existing Bridge protocol oversized-request test remains in place. The MCP protocol test
asserts both diagnostic RPC names are absent from the tool list.

Phase B recorder tests continue to cover all four completeness values, negative
unaccounted rollups, established versus unestablished not-retained reasons, and recorder
projection allowlists.
