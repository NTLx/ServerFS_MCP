## Release scope

v0.23.0 introduces **Deterministic Repo Ops**, a generic non-Agent repository capability for opted-in Linux ServerFS workdirs. It is not LLM_WiKi-specific; LLM_WiKi was the first public acceptance consumer.

The public MCP surface remains narrow:

- `inspect_repo` — bounded status/diff/action inspection;
- `run_repo_action` — operator-defined deterministic named actions;
- `commit_repo_changes` — explicit-path hardened Git commit;
- `push_repo` — exact current-upstream push.

The current source also supports fixed operator-configured release action kinds through `run_repo_action`: `release_tag` for a validated exact tag at the captured clean `main` HEAD, and `publish_npm` for dispatching one fixed GitHub Actions publication workflow. These do not expose arbitrary Git refs, workflows, executable/argv, environment, force, or shell syntax.

Repo Ops is independently gated from Agent delegation and never falls back to `submit_agent_task`. The v0.23.0 Repo Ops support claim is **Linux Host Bridge only**; native Windows/macOS Repo Ops enablement is not claimed.
