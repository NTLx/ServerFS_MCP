## 核心约束

每个非默认实例具有一个已签名的 `ServerFSServiceManager.app`，其 `Contents/Library/LaunchAgents/*.plist` 在 staging 时生成并随 App 一次性签名。macOS `SMAppService.agent(plistName:)` 通过这个签名边界注册服务，因此不支持向运行中的 App 随意追加 Connector。

| Provider | 基础 service key | 具名 service key 示例 | launchd label 示例 |
|---|---|---|---|
| Cloudflare | `cloudflare` | `cloudflare.blue` | `com.ntlx.serverfs.dev.cloudflare.blue` |
| OpenAI | `tunnel` | `tunnel.blue` | `com.ntlx.serverfs.dev.openai.blue` |

`connector_id` 采用与公共 `instance_id` 相同的 ASCII 小写 slug 语法，按 Provider 独立去重。不同 Provider 可使用同一个 ID；基础无 ID 的服务不改名。默认/生产实例绝不采用这条扩展路径。
