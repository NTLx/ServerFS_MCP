- **Linux/VPS: PASS.** Current root and Agent Bridge deterministic, lint, format,
  compatibility, security, Compose and scratch-image gates passed. Phase E performance
  work is referenced from its existing report and was not repeated.
- **Windows diagnostics/native pipe: PASS.** Existing Phase F evidence proves the
  diagnostics CLI over the current-user SID-verified Named Pipe, including SID
  verification before request bytes. **Windows full-root native-current-user PASS
  evidence is still missing.** Its earlier temporary/sandbox environment run had
  failures; focused Windows diagnostics/native-pipe acceptance does not substitute for
  the full-root acceptance. See the Windows report.
- **macOS deterministic acceptance: PASS; live diagnostics: BLOCKED.** The supported
  arm64/macOS 27.0.1 host passed deterministic root, Bridge and focused
  native/service/diagnostics gates in an isolated detached worktree. The current-user
  AF_UNIX endpoint is reachable from the v0.22 CLI, but the running older Bridge returns
  `METHOD_NOT_FOUND: unknown bridge method: diagnostics.snapshot`. Safe upgrade/restart
  must happen out-of-band after active tasks and writer leases are terminal/released.
  See
  [`v0.22.0-phase-f-macos-acceptance-2026-10-22.md`](v0.22.0-phase-f-macos-acceptance-2026-10-22.md).
- **Overall Phase F / Phase G: NOT COMPLETE; TWO BLOCKERS remain:** (1) Windows
  full-root native-current-user PASS evidence and (2) macOS live diagnostics against an
  updated Bridge. No tag or release is permitted.
- Release-facing README, operator documentation and website updates are **deferred until
  both platform blockers are cleared**. Their current v0.21.0 stable-release statements
  remain accurate for the unreleased v0.22.0 state.
