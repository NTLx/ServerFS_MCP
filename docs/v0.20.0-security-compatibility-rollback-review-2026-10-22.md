## Verdict

**PASS for §17 criterion 9.** The reviewed v0.20 implementation and current documentation/test changes show no widened authority, weakened maintainer invariant, or unsafe persisted-state migration relative to v0.19. A concrete rollback to retained v0.19 artifacts and existing operator configuration is available on each supported deployment family. This verdict is limited to the reviewed diff and recorded evidence; it does not imply Registry preview interoperability or publication acceptance.

Registry preview limitations remain **Not verified and non-blocking**: a Registry client installing/launching OCI + Streamable HTTP, official `/v0.1/validate`, and namespace claim/publication. No implementation blocker was found for criterion 9. Criterion 3 remains independently pending native Windows/macOS execution of the newly added stdio subprocess acceptance test, as recorded in the acceptance record.
